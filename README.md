# 🌐 Personal Portfolio Website

A modern, responsive, and interactive portfolio website showcasing my projects, research publications, certifications, technical skills, and professional journey as an aspiring AI/ML Engineer.

Designed with a clean dark aesthetic, smooth animations, glassmorphism-inspired UI, and fully responsive layouts, this portfolio serves as a central place to present my work and achievements.

---

## ✨ Features

* 🎨 Modern dark-themed UI
* 📱 Fully responsive design
* ⚡ Smooth scroll and reveal animations
* 🖱️ Custom animated cursor (desktop)
* 🌫️ Glassmorphism-inspired navigation
* 👨‍💻 About Me section
* 🚀 Projects showcase
* 📄 Research publications
* 🏆 Certifications & achievements
* 📬 Contact section with social links
* ⚙️ Easy configuration through a single JavaScript object

## ⚙️ Customization

Most portfolio content can be updated from the `CONFIG` object inside the JavaScript file, including:

* Personal information
* Skills
* Projects
* Research papers
* Certifications
* Social media links
* Contact details

No framework or build tools are required.
